## 1.3 「参加型」AI紙芝居を作ろう

このAI紙芝居アプリは、さまざまな物語を作って、読み込んで、遊べるようになっています。
いま遊んでもらったアプリは、「浦島太郎」でした。 この台本では、浦島太郎が竜宮城に到着したときに、

これから、乙姫様にどんなダンスポーズをさせるかを考え、棒人間の絵を描き、それをもとに乙姫様の絵をAIに描かせてみます。
さらに、ダンスポーズを認識できるようにAIをトレーニングします。
最後に、紙芝居の台本を更新し、AIによる成果物をとりまとめて、作品全体を遊べるようにします。

# 2. AIに乙姫様を描いてもらおう

それではさっそく、乙姫様にどのようなダンスを踊らせたいかを考えましょう。
あなたは、どんな乙姫様にどんなダンスを踊らせたいですか？　あなた自身は、どんなダンスをしたいですか？

## 2.1 ダンスのポーズを考えて棒人間の絵で下書きする

そのダンスの「決めポーズ」を、最低2つ、最大4つ、親子で考えてください。

* それぞれのポーズが、他のポーズとはっきり違うものになるようにしてください。
* ポーズごとに左右の腕の角度や肘の曲げ伸ばしを変え、違いがはっきりわかるようにしてください。
* 上半身だけでポーズの見分けがつくようにしてください（この体験会のカメラには下半身が映りにくいため、下半身だけが異なるポーズにはしないでください）。

### 2.1.1 手書きで棒人間の絵を描く

親子で相談・分担しながら、その「決めポーズ」の絵を、「棒人間」として描いてください。

* それぞれのポーズの絵を、配布されているメモ用紙に筆記用具を用いて描いてください。
* 細部をリアルに描く必要はありません。また、絵の上手下手は関係ありません。
* 大事なことは、上半身の大きな動きがわかるように描くことです。
* 下半身は認識しにくいため、下半身だけが異なるポーズにはしないでください。
* うまく描けなかったら、別の紙に描き直しをしてもかまいません。
* 最低2つ、最大4つの「棒人間」を描けたら、次の作業に進みます。

「棒人間」の絵を描くときには、たとえば次のような感じに描けば大丈夫です。

![](../../images/image11.png){alt="棒人間で描いた決めポーズの例" style="width: 180px;"}

ここでは、WebブラウザのEdgeを使って、M365 Copilotの画面を開きます。

この体験会では、あらかじめサインイン済みの状態のEdgeのタブを用意しています。

### 5.3.4 ポーズのサンプル画像を撮影する

1つのポーズごとに、5〜10枚の「サンプル」画像を撮影していきます。
まずは、実際にやってみましょう。

* 液晶ディスプレイとカメラを「1.1.1 教室内の座席に座るとき」節の図における「矢印」の方向に回転させてください。
* 小学生の方は、席を立ってウェブカメラの前に移動し、ポーズを取ってください。
* プレビュー画像の中では、ポーズを取っている人の姿勢をAIが認識した際に、「ボーン（骨）」と呼ばれる線が表示されます。 ボーンは人体を簡略化した関節のおおまかな位置を表す「丸」と骨を表す「線」で構成されます。
* 姿勢が正しく認識されなかった箇所については、ボーンの「丸」や「線」の表示が消えてしまっています。

![](../../images/bone.png){alt="Teachable Machineのボーン表示" style="width: 120px;"}

* 保護者の方は、(1) ポーズ画像とカメラのプレビュー映像とが同じ姿勢になっていること、(2) ボーンの「丸」や「線」が画像と重ね合わされて正しく表示されていることが、同時に達成されている瞬間を見計らって、声かけ・アドバイスをしながら「長押しして録画」ボタンを押し、「サンプル」の撮影をしてください。
* 撮影されたポーズの姿勢が崩れてしまっていたり、その際にボーンが認識されていなかったりしたサンプル画像は、削除してください。削除するには、サンプル画像上にマウスを重ねたときに表示される「ゴミ箱」ボタンを押してください。
* 1つのポーズごとに、微妙に姿勢を変えながら、5〜10枚を撮影して画像を用意してください。
* 他の親子が画像に写り込んでしまった場合には、その画像を削除してください。

![](../../images/tmpose-samples.png){alt="撮影したポーズのサンプル画像" style="width: 350px;"}

Teachable Machineを用いて、
ポーズごとに整理された形で「サンプル」画像を撮影して保存することを、
「サンプルの収集」と呼びます。
サンプルを収集したものをもとに、あるクラスにどんな共通の特徴があるのか、
他のクラスとはどのような特徴の違いがあるのかについて、AIを「学習」させます。
このような「学習」を、ここでは「トレーニング」と呼んでいます。
そうして、AIがいろいろなものを識別できるように「トレーニング」した内容のことを、AIの「モデル」と呼びます。
この「モデル」を用いることで、AIは、いろいろなポーズを識別できるようになります。

「トレーニング」をするときに、1つのポーズについてのサンプル画像が少ない場合には、
覚える材料が不足しているため、性能の良いモデルが作れません。
サンプルの画像が、同じような画像ばかりでも、枚数を増やせたことにはなりません。
逆に、画像の枚数が多すぎると、トレーニングに時間がかかってしまいます。

どのようなサンプルを収集すれば、性能のよい「モデル」の「トレーニング」ができるでしょうか？
よりよい「学習」ができるでしょうか？　工夫しながら取り組んでください。

すべてのポーズについてサンプルの収集を終えたら、次の「5.4 モデルをトレーニングする」節に進んでください。

画面中央付近の「モデルをトレーニングする」のボタンをクリックし、しばらく待ってください（数分間かかる場合があります）。

![](../../images/tmpose-train.png){alt="モデルをトレーニングするボタン" style="width: 150px;"}
![](../../images/tmpose-training.png){alt="モデルのトレーニング中の画面" style="width: 150px;"}

## 5.5 モデルを確認する

トレーニングが完了したら、AIによるポーズの識別がうまく動作するかどうかを確認しましょう。

小学生の方は、席を立ってウェブカメラの前に移動し、ポーズを取ってください。
「プレビュー」をクリックすると、カメラが起動し、撮影された人物のポーズに応じて、
トレーニング済みのAIが、どのポーズを認識したかを、棒グラフの長さで表示します。
棒グラフの長さが長いほど、AIがそのポーズを認識していることを意味します。

カメラの前で、わかりにくいポーズや、まぎらわしいポーズを取った場合には、AIが間違って認識することがあります。
また、もともとのポーズ画像の段階で、ポーズが区別しにくいものであった可能性もあります。
うまく認識できていない場合には「5.3 ポーズを撮影する」節に戻ってやり直してください。

![](../../images/tmpose-model.png){alt="トレーニングしたモデルを確認するプレビュー画面" style="width: 400px;"}

モデルのトレーニングはうまくいきましたか？
あとで、ポーズの再撮影やポーズの追加がしたくなったときのために、
プロジェクトを保存しておくことができます。

画面左上端のTeachable Machineのタイトルの左側にある「三」のアイコンをクリックして
表示されるメニューの中程の「プロジェクトをファイルとしてダウンロード」をクリックしてください。

![](../../images/image57.png){alt="Teachable Machineのプロジェクトダウンロードメニュー" style="width: 200.50px;"}

ダウンロードしたファイルは「ダウンロード」フォルダに「project.tm」という名前で保存されているので、
配布資料フォルダの中の「tmpose」フォルダに移動させておいてください。

このメニューの「ファイルからプロジェクトを開く」をクリックして、保存しておいた「project.tm」ファイルを選択することで、
必要な場合に、TeachableMachineでの作業を再開することができます。

## 5.6 モデルをクラウドにエクスポートする

次は、トレニーニングされたモデルを、AI紙芝居アプリで使えるようにしましょう。

![](../../images/model-upload.png){alt="モデルのアップロード設定画面" style="width: 500px;"}

それまで、「共有可能なリンク：」欄には、灰色の文字で\[...\]というようなダミーのリンク文字列が表示されていましたが、アップロードが完了すると、ここに、あなたのモデルのリンクが表示されます。

> **⚠️注意**
> * 保存したプロジェクトの中には、AIのトレーニングに用いるためのものとして撮影したサンプル画像が含まれています。サンプル画像には、個人情報などが含まれる場合がありますので、取り扱いには十分に注意してください。

# 6. 台本ファイルの修正をしよう

「参加型」AI紙芝居アプリは、
物語を記述した「台本ファイル」をもとに動作します。
ここでは、台本ファイルの修正方法について説明します。

## 6.1 台本ファイルの編集を開始する

配布資料フォルダ内の「stories」→「my-urashima」フォルダにある、紙芝居の台本ファイル「my-urashima.txt」
のアイコンの上で「右クリック」し、
表示されたメニューの中から「メモ帳で編集する」をクリックする、あるいは「プログラムから開く」を選択して「メモ帳」をクリックしてください。

![](../../images/image58.png){alt="メモ帳で開いたmy-urashima.txt" style="width: 601.70px;"}

台本ファイルの中では、行ごとに、台本を構成するさまざまな設定が記述されています。

行の1文字目に記号「`#`」がつけられていると、その行の設定は無効になります。

my-urashima.txtファイルでは、さまざまな状況に対応した設定候補を、行の1文字目に記号「`#`」をつけて、あらかじめ無効にした状態で並べています。

my-urashima.txtファイルを修正する際には、有効にしたい設定行の1文字目にある「`#`」を削除することで、設定をカスタマイズできます。

行が「---」という内容の場合は、物語のシーンの区切りを表しています。最初の「---」より前では、物語のすべてのシーンで共通して利用する「アセット」などを設定します。

## 6.2 モデルのURLを設定する

AI紙芝居アプリでは、それぞれのシーンで、カメラ画像から身体のポーズを認識して、
それに応じて物語を進めるという仕組みをつくることができます。
そのためには、5章で行ったように、事前にカメラの画像でポーズを撮影し、
Teachable Machineを使って、これを識別するためのAIモデルをトレーニングし、
その成果物であるモデルをクラウドにエクスポートして共有可能にしたものを使います。

ここでは、シーン3「竜宮城到着」のモデルのURLを修正します。
my-urashima.txt内の「`# scene 3`」という行を探し、その直下の「`TMPoseURL=`」で始まる行を見てください。
この台本では、もともとは、浦島太郎がダンスをするポーズを認識するモデルのURLが設定されています。

```
---
# scene 3
TMPoseURL=https://teachablemachine.withgoogle.com/models/…
```

それでは、これを、あなたが作った乙姫様のダンスのポーズを認識するように修正しましょう。
先ほどまでの流れでは、5.6節でリンクをコピーした状態となっているはずなので、
「`TMPoseURL=`」より後ろの部分にコピーした内容を貼り付け、既存の内容を
次のように書き換えてください。

```
---
# scene 3
TMPoseURL=https://teachablemachine.withgoogle.com/models/あなたのモデルのURLの末尾部分
```

> **確認**
>
> 間違った内容を貼り付けていないか、「=」などの記号を消していないかを確認してください。

## 6.3 アセットを設定する

ここでいう「アセット」とは、このAI紙芝居アプリにおける、背景画像、コスチューム画像、効果音、BGMなどの素材の総称です。
アセットを設定する行は「`asset=`」で始めます。カンマ区切りの1つ目の値がアセット名、2つ目の値がアセットのアドレスを表します。

my-urashima.txtファイルでは、「Princess」という名前のScratchスプライトにあるコスチュームを、アセットとして設定しています。

ここでは、「`asset=p1,costume:Princess`」という設定について説明します。

`asset=p1,costume:Princess`

| 設定行の部分 | 意味 |
| ----- | ----- |
| asset= | この行で「アセット」を設定することを宣言する |
| p1 | アセット名は「p1」であることを表します。 |
| , | 区切り文字「,」はアセット名には含むことができないルールとしており、アセット名の終端を表します。 |
| costume: | アセットのアクセス先は「costume:」であることを表します。 |
| Princess | コスチュームを探す際には「Princess」という名前のスプライトの中から、アセット名(p1)と同じ名前のコスチュームを探します。 |

それではここで、あなたが作成した乙姫様の画像をアセットとして設定しましょう。

アセットの設定を有効にするには、対象行の行頭にある「`#`」を削除します。これにより、「Princess」というスプライトから、アセット名と同じ名前のコスチューム画像を登録できます。

> **確認**
>
> 必要な行だけ、行頭の「`#`」を削除してください。

```
#asset=p1,costume:Princess
#asset=p2,costume:Princess
#asset=p3,costume:Princess
#asset=p4,costume:Princess
```

以下の6.3.1、6.3.2、6.3.3節は、場合ごとの設定内容を示したものです。このうち、いずれか1つの形で設定してください。

### 6.3.1 ポーズ2つを作成した場合の設定

「p1」をアセット名として、Princessというスプライト名の「p1」という名前のコスチューム画像を登録します。

「p2」をアセット名として、Princessというスプライト名の「p2」という名前のコスチューム画像を登録します。

```
asset=p1,costume:Princess
asset=p2,costume:Princess
#asset=p3,costume:Princess
#asset=p4,costume:Princess
```

### 6.3.2 ポーズ3つを作成した場合の設定

「p1」をアセット名として、Princessというスプライト名の「p1」という名前のコスチューム画像を登録します。

「p2」をアセット名として、Princessというスプライト名の「p2」という名前のコスチューム画像を登録します。

「p3」をアセット名として、Princessというスプライト名の「p3」という名前のコスチューム画像を登録します。

```
asset=p1,costume:Princess
asset=p2,costume:Princess
asset=p3,costume:Princess
#asset=p4,costume:Princess
```

### 6.3.3 ポーズ4つを作成した場合の設定

「p1」をアセット名として、Princessというスプライト名の「p1」という名前のコスチューム画像を登録します。

「p2」をアセット名として、Princessというスプライト名の「p2」という名前のコスチューム画像を登録します。

「p3」をアセット名として、Princessというスプライト名の「p3」という名前のコスチューム画像を登録します。

「p4」をアセット名として、Princessというスプライト名の「p4」という名前のコスチューム画像を登録します。

```
asset=p1,costume:Princess
asset=p2,costume:Princess
asset=p3,costume:Princess
asset=p4,costume:Princess
```

## 6.4 アクターのポーズを設定する

ここでいう「アクター」とは、このAI紙芝居に表示されるキャラクターの呼び名です。「浦島太郎」「亀」「乙姫様」などのすべてのキャラクターが「アクター」です。このAI紙芝居アプリでは、Scratchの標準的な用語・概念であるスプライトを直接使わず、「Actor」という英語名の特殊なスプライトをクローン（複製）し、スプライト変数「アクター名」で名前をつけて管理しています。

アクターは「アクション」を実行できます。台本ファイルの中で、行頭が「`action=アクター名:`」で始まる設定を「アクターアクション」と呼びます。

ここでは、「Princess」という名前のアクターに「pose」というアクションをさせる設定例を見てみましょう。

`action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...`

| 設定行の部分                               | 意味                                                                                         |
|--------------------------------------------|--------------------------------------------------------------------------------------------|
| action=                                    | この行は「アクション」を設定するものであることを宣言します                                                              |
| Princess:                                  | この行はアクター名「Princess」の「アクターアクション」であることを宣言します                                                 |
| pose:                                      | この行はアクターアクション「pose」を設定することを宣言します                                                           |
| p1,p2,p1,p2                                | スキンのアセット名をカンマ区切りで列挙します。この例では「p1」「p2」「p1」「p2」の順に、アクターの見た目を変化させます                            |
| p1,p2,p1,p2                                | Teachable Machineのポーズのクラス名（ポーズ名）をカンマ区切りで列挙します。この例ではp1,p2,p1,p2の順番でポーズを認識されます               |
| Drum Funky,Drum Funky,Drum Funky,Drum Funk | 効果音のアセット名をカンマ区切りで列挙します。この例では「Drum Funky」「Drum Funky」「Drum Funky」「Drum Funky」の順番で効果音が鳴らされます |

それでは、my-urashima.txtファイル内に並ぶ3つの「`#action=Princess:pose:`」行のうち、設定を有効にしたい行の行頭にある「`#`」を削除してください。

> **確認**
>
> 必要な行だけ、行頭の「`#`」を削除してください。

```
#action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```

以下の6.4.1、6.4.2、6.4.3節は、場合ごとの設定内容を示したものです。このうち、いずれか1つの形で設定してください。

### 6.4.1 ポーズ2つを作成した場合の設定

3行のうち1行目、アセット名部分に「p1」「p2」が書かれている行の行頭の\#記号を削除してください。ここでは、p1,p2のポーズ2つが2回繰り返されます。

```
action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```

### 6.4.2 ポーズ3つを作成した場合の設定

3行のうち2行目、アセット名部分に「p1」「p2」「p3」が書かれている行の行頭の\#記号を削除してください。ここでは、p1,p2,p3のポーズ3つが2回繰り返されます。

```
#action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```

### 6.4.3 ポーズ4つを作成した場合の設定

3行のうち3行目、アセット名部分に「p1」「p2」「p3」「p4」が書かれている行の行頭の\#記号を削除してください。ここでは、p1,p2,p3,p4のポーズ4つが2回繰り返されます。

```
#action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```
