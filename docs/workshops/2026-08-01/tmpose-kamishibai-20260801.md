# 0. この教材と体験会について

## 0.1 この教材の一次配布元

AI紙芝居アプリおよびこの教材は、久保裕也（千葉商科大学　総合政策学部　教授）による研究プロジェクトの成果物です。正式版の配布は、[https://kubohiroya.github.io/tmpose-kamishibai/](https://kubohiroya.github.io/tmpose-kamishibai/) で行うものとします。
AI紙芝居アプリも、ここから遊べます。

## 0.2 この教材の狙い

このAI紙芝居アプリでは、さまざまな物語を読み込んで遊べます。
この体験会では、そうした物語のひとつとして「浦島太郎」をサンプルとします。
もともとの台本では、浦島太郎が竜宮城に到着したときに、 利用者といっしょに
浦島太郎がダンスをするようになっていますが、その台本を書き換えるなどして、乙姫様といっしょにダンスをする内容に変えてみることにします。

乙姫様にどんなダンスポーズをさせるかを考え、棒人間の絵を描き、それをもとに乙姫様の絵をAIに描かせてみましょう。さらに、ダンスポーズを認識できるようにAIをトレーニングしてみましょう。最後に、紙芝居の台本を更新し、AIによる成果物をとりまとめて、作品全体を遊べるようにしてみましょう。

## 0.3 この体験会で学ぶこと

この体験会では、

* 画像づくりAI
* ポーズ認識AI
* 紙芝居プログラミングアプリ

といった技術を組み合わせて、

**「AI技術を応用して、紙芝居の物語の中に参加する仕組み」**

を作ります。楽しんでください！

## 0.4 この体験会が想定する参加者

この体験会は、「小学生の児童およびその保護者のペア」で参加していただくことを想定しています。

* AI利用経験は問いません
* プログラミング経験（Scratchなど）は問いません

なお、念のため、次のことを確認させてください。

* マウスやキーボードの操作ができますか？
* EdgeなどのWebブラウザの操作ができますか？
* Windowsにおけるフォルダやファイルの概念を理解していますか？

わからないという人は、この会を通じてスタッフがサポートしますので、安心してください。

# 2. AIに乙姫様を描いてもらおう

それではさっそく、乙姫様を踊らせる＝あなたが踊りたいダンスについて考えましょう。
あなたは、どんな乙姫様にどんなダンスを踊らせたいですか？　あなた自身は、どんなダンスをしたいですか？

## 2.1 ダンスのポーズを考えて棒人間の絵で下書きする

そのダンスの中での、「決めポーズ」を、 最低2つ、最大4つのポーズとして、親子で考えてください。

* それぞれのポーズが、他のポーズとはっきり違うものになるようにしてください
* ポーズごとに、左右の腕の角度、肘の曲げ伸ばしを変化させて、それぞれのポーズが、はっきりと違うものになるようにしてください
* 上半身だけでポーズの見分けがつくようにしてください（この体験会でのカメラは、下半身がカメラに映りにくいので、 下半身だけが異なるようなポーズにはしないようにしてください）

### 2.1.1 手書きで棒人間の絵を描く

親子で相談・分担しながら、その「決めポーズ」の絵を、「棒人間」として描いてください。

* それぞれのポーズの絵を、配布されているメモ用紙に筆記用具を用いて描いてください。
* 細部をリアルに描く必要はありません。また、絵の上手下手は関係ありません。
* 大事なことは、身体全体での、大きな動きがわかるように描くことです。
* 下半身は認識しにくいので、 下半身だけが異なるようなポーズにしないようにしてください。
* うまく描けなかったら、別の紙に描き直しをしてもかまいません。
* 最低2つ、最大4つの「棒人間」を描けたら、次の作業に進みます。

「棒人間」の絵を描くときには、たとえば次のような感じに描けば大丈夫です。

## 2.3 生成AIでポーズの絵を描く

ここからは、乙姫様がダンスのポーズをする絵を描きましょう。
そのために、ここでは「生成AI」と呼ばれる技術を用いて、
人間が素材とする画像や言葉による指示を与えることで、目的とする画像を生成させることとします。

### 2.3.1 生成AIの画面を開く

この体験会では、生成AIの一種であるMicrosoftの「M365 Copilot」を使うこととします。

* M365 Copilotは、Microsoftの「Word」「Excel」「PowerPoint」などのアプリの中で使えるAI機能ですが、
ここでは、WebブラウザのEdgeを使って、M365 Copilotの画面を開きます。
* M365 Copilotは、Microsoftのアカウントでサインインして使う必要がありますが、
この体験会では、あらかじめサインイン済みの状態のEdgeのタブを用意しています。
* M365 Copilotは、利用対象年齢が13歳以上となっているため、小学生が使うことは認められていません。
この体験会においては、M365 Copilotの操作は、保護者の方が行ってください。

Windows画面の一番下の中央付近に、次のようなアイコンが表示されています。これはWindows上でインターネット上のWebコンテンツと呼ばれているものを表示したり操作したりする、Webブラウザというもののひとつ、「Edge」というアプリを起動するためのものです。

![](../../images/image18.png){style="width: 82.00px;"}

このEdgeのアイコンをクリックして、Edgeのアプリを開きます。

この体験会では、事前に、WebブラウザのEdgeで、M365 Copilotをサインイン済みの状態として準備をしています。
Edgeのアプリ内で、次の図のような「チャット | M365 Copilot」のタブを選択してください。

画面中央に「こんにちは。何かお手伝いできることはありますか？」と表示されていることを確認してください。

### 2.3.7 ポーズ画像ファイルをもっと作成する

ポーズ画像ファイルが作成できたことを確認したら、「2.3.2 立ち絵の画像をアップロードする」節に戻り、
あらかじめ計画していた、作成したいポーズの数だけ、作業を繰り返し行なってください。

次のポーズからは、「プロンプト例」の文面に、

# 6. 台本ファイルの修正をしよう

## 6.1 台本ファイルの編集を開始する

配布資料フォルダの中の、紙芝居の台本ファイル「my-urashima.txt」ファイルをダブルクリックし、「メモ」アプリで開いてください。

![](../../images/image58.png){style="width: 601.70px;"}

台本ファイルの中では、行ごとに、台本を構成するさまざまな設定が記述されています。

行の1文字目に記号「\#」がつけられていると、その行の設定は無効化されます。

my-urashima.txtファイルでは、さまざまな状況に対応した設定の候補を、行の1文字目に記号「\#」をつける仕組みを用いて、あらかじめ無効化した形で書いて並べてあります。

my-urashima.txtファイルを修正する際には、有効化したい設定の行の1文字目の「\#」を削除することで、設定をカスタマイズすることができます。

行が「---」という内容の場合は、物語のシーンの区切りを表しています。最初の「---」より前は、物語の全てのシーンで共通して利用される「アセット」に関する設定などを行います。

## 6.2 モデルのURLを設定する

AI紙芝居アプリでは、それぞれのシーンで、カメラ画像から身体のポーズを認識して、それに応じて物語を進めるという仕組みをつくることができます。そのためには、5章で行ったように、事前にカメラの画像でポーズを撮影し、これを認識するためのAIモデルTeachable Machineのトレーニングをし、その成果物であるモデルをクラウドにエクスポートして共有可能にしておきます。ここでいう「モデルのURL」とは、5.6節でモデルをクラウドにアップロードして共有可能にしておいたもののURLのことです。

たとえば、シーン3「竜宮城到着」のモデルのURLの設定は、my-urashima.txtの123行目（\# scene 3という行の下の行）にあります。この台本では、もともと浦島太郎がダンスをするポーズを認識するモデルのURLが設定されています。

それでは、これを、あなたが作った乙姫様のダンスのポーズを認識するように修正しましょう。5.6節でリンクをコピーしておいたものを、123行目での、TMPoseURL=以下の部分に貼り付けして既存の内容を置き換えてください。

```
---
# scene 3ーーー
TMPoseURL=https://teachablemachine.withgoogle.com/models/…
```

【間違った内容を貼り付けしていないか、=記号などを消してしまっていないか確認してください】

## 6.3 アセットを設定する

ここでいう「アセット」とは、このAI紙芝居アプリにおいて、背景画像、コスチューム画像、効果音、BGMなどの素材を統合した呼び名です。これは、ScratchやTurboWarpの標準的な用語・概念ではなく、TurboWarp機能拡張による[turbowarp-asset-manager](https://github.com/kubohiroya/turbowarp-asset-manager)で実現される用語・概念です。

アセットを設定するためには、その行を asset= で始めます。カンマ区切りでの1つめの値がアセット名、2つめの値がアセットのアドレス値を表します。

my-urashima.txtファイルの22行目から25行目では、Scratchのスプライトで Princess という名前のものについてのコスチュームを、アセットとして設定しています。

ここでは、22行目の設定がどのようになっているのかを説明します。

**asset=p1,costume:Princess**

| 設定行の部分 | 意味 |
| ----- | ----- |
| asset= | この行で「アセット」を設定することを宣言する |
| p1 | アセット名は「p1」であることを表します。 |
| , | 区切り文字「,」はアセット名には含むことができないルールとしており、アセット名の終端を表します。 |
| costume: | アセットのアクセス先は「costume:」であることを表します。 |
| Princess | コスチュームを探す際には「Princess」という名前のスプライトの中から、アセット名(p1)と同じ名前のコスチュームを探します。 |

それではここで、あなたが作成した乙姫様の画像をアセットとして設定しましょう。

アセットの設定を有効化したい行の内容について、行頭の\#記号を削除してもらいます。その行の設定により、アセット名として、Princessというスプライト名の同名のコスチューム画像を登録することができるのです。

【必要な行についてだけ、行頭の\#を削除するという方針について確認してください】

```
#asset=p1,costume:Princess
#asset=p2,costume:Princess
#asset=p3,costume:Princess
#asset=p4,costume:Princess
```

以下の 6.3.1 、6.3.2、6.3.3 節は、場合ごとの設定内容を示したものです。このうちいずれかひとつの形で設定を実施してください。

### 6.3.1 ポーズ2つを作成した場合の設定

「p1」をアセット名として、Princessというスプライト名の「p1」という名前のコスチューム画像を登録します。

「p2」をアセット名として、Princessというスプライト名の「p2」という名前のコスチューム画像を登録します。

```

asset=p2,costume:Princess
#asset=p3,costume:Princess
#asset=p4,costume:Princess
```

「p2」をアセット名として、Princessというスプライト名の「p2」という名前のコスチューム画像を登録します。

「p3」をアセット名として、Princessというスプライト名の「p3」という名前のコスチューム画像を登録します。

```
#asset=p4,costume:Princess
```

### 6.3.3 ポーズ4つを作成した場合の設定

「p1」をアセット名として、Princessというスプライト名の「p1」という名前のコスチューム画像を登録します。

「p2」をアセット名として、Princessというスプライト名の「p2」という名前のコスチューム画像を登録します。

「p3」をアセット名として、Princessというスプライト名の「p3」という名前のコスチューム画像を登録します。

## 6.4 アクターのポーズを設定する

ここでいう「アクター」とは、このAI紙芝居で表示されるキャラクターを表す呼び名です。「浦島太郎」「亀」「乙姫様」などの全てのキャラクターは、「アクター」です。このAI紙芝居アプリでは、Scratchの標準的な用語・概念であるスプライトを直接使わずに、「Actor」という英語名の特殊なスプライトのクローン（複製）し、これを識別できるようにスプライト変数「アクター名」を用いて名前をつけて管理しています。

アクターは、「アクション」をすることができます。台本ファイルの中で行頭が「action=アクター名:」で始まる設定のことを「アクターアクション」と呼んでいます。

ここでは、my-urashima.txtファイルの140行目で「Princess」という名前のアクターに、「pose」というアクションをさせる例を見てみましょう。

**action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...**

| 設定行の部分                               | 意味                                                                                                                                                     |
|--------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| action=                                    | この行は「アクション」を設定するものであることを宣言します                                                                                               |
| Princess:                                  | この行はアクター名「Princess」の「アクターアクション」であることを宣言します                                                                             |
| pose:                                      | この行はアクターアクション「pose」を設定することを宣言します                                                                                             |
| p1,p2,p1,p2                                | アセット名「p1」「p2」「p1」「p2」の順番で示されたコスチュームが用いられて、アクターの見た目を変化させることを指定します                                 |
| p1,p2,p1,p2                                | Teachable Machineのポーズのクラス名（ポーズ名）をカンマ区切りで列挙します。p1,p2,p1,p2の順番でポーズを認識することを指定します                           |
| Drum Funky,Drum Funky,Drum Funky,Drum Funk | アセット名「Drum Funky」「Drum Funky」「Drum Funky」「Drum Funky」の順番で示された効果音が用いられ、ポーズの認識に合わせて音が鳴らされることを指定します |

それでは、my-urashima.txtファイルの140行目-142行目の3行のうちで、設定を有効化したい行の内容について、行頭の\#記号を削除してください。

【必要な行についてだけ、行頭の\#を削除するという方針について確認してください】

```
#action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```

以下の 6.4.1、 6.4.2、 6.4.3 節は、場合ごとの設定内容を示したものです。このうちいずれかひとつの形で設定を実施してください。

### 6.4.1 ポーズ2つを作成した場合の設定

3行のうち1行目、アセット名部分に「p1」「p2」が書かれている行の行頭の\#記号を削除してください。ここでは、p1,p2のポーズ2つが2回繰り返されます。

```
action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```

### 6.4.2 ポーズ3つを作成した場合の設定

3行のうち2行目、アセット名部分に「p1」「p2」「p3」が書かれている行の行頭の\#記号を削除してください。ここでは、p1,p2,p3のポーズ3つが2回繰り返されます。

```
#action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```

### 6.4.3 ポーズ4つを作成した場合の設定

3行のうち3行目、アセット名部分に「p1」「p2」「p3」「p4」が書かれている行の行頭の\#記号を削除してください。ここでは、p1,p2,p3,p4のポーズ4つが2回繰り返されます。

```
#action=Princess:pose:p1,p2,p1,p2:p1,p2,p1,p2:Drum Funky,Drum Funky,Drum Funky,...
#action=Princess:pose:p1,p2,p3,p1,p2,p3:p1,p2,p3,p1,p2,p3:Drum Funky,Drum Funky,...
action=Princess:pose:p1,p2,p3,p4,p1,p2,p3,p4:p1,p2,p3,p4,p1,p2,p3,p4:Drum...
```
