# v4.0.0-rc.44 — 物語制御をDSL 4.0 RCの標準機能へ

`if`・固定回数の`repeat`・一覧の`forEach`・型付き参照をStandardのauthoring／playback／CLIで有効にします。宣言は`kamishibai: '4.0'`のままで、4.1系列は作りません。専用台本ブロックと各回の一覧フォームを使えます。Scratch標準の制御ブロックは引き続き非対応で、診断の日本語ブロック名・ステージ／スプライト名から該当位置へ戻ります。

## 配布と対応版

- GitHub prerelease: `v4.0.0-rc.44`
- Standard SB3: `kamishibai-4.0.0-rc.44.sb3`。タイトル・メニュー・runtimeを同じrelease sourceから生成します。
- 公開Editorは対応済みのGUIを利用し、Docs・SamplesはこのReleaseのcommit／固定SB3へ既存の依存更新経路で追従します。
- npm公開・dist-tag変更は保留です。npmのrc.43を、この機能を備えたCLIとして案内しません。
- CLIは`v4.0.0-rc.44`の別checkoutで`pnpm install --frozen-lockfile`と`pnpm build:lib`を実行し、`node bin/turbowarp-kamishibai.mjs`を使います。追加の`--narrative-control`は不要です。
- 推奨安定版3.2.3・過去の版付きSB3／Playerは維持します。

## 互換性・検証・切戻し

通常の4.0台本の意味、低水準の既定OFF、明示的な無効化、旧runnerの拒否を維持します。行・固定回数は1024、列は32、入れ子は16までで、未選択側・0回・空一覧の本体も検証します。

Standard昇格の対象76テストと生成runtimeの有効／無効・決定性2テスト、build・typecheck・変更ソースlint／formatを確認しました。PR #990の必須CIは成功しています。候補はsource identity・SHA-256・サイズを固定し、そのPRのCIで再構築一致を確認してから公開します。公開実物のEditor編集・再生・停止再開・診断移動／強調とDocs／Samplesの確認結果は[Issue #989](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/989)へ記録します。

問題時はrc.43のSB3・台本・Docs／Samples導線を一式で戻します。新構文を残したままflagだけをOFFにしません。凍結候補・公開済みtag／assetを同版で作り直さず、修正は次RCで公開します。Appの進行中の別作業は変更しません。
