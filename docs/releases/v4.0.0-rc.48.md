# v4.0.0-rc.48

DSL 4.0 release candidateの改訂です。PR #1001のsession解放再試行・遅延カメラ資源の所有権保持・未解放状態の照会例外への対処を含みます。失敗/未確認のownerを保持して明示disposeで再試行し、成功済みstepを繰り返しません。通常操作は閉じたまま維持します。

## 公開範囲

GitHub prerelease・版付きStandard SB3・Pages Playerを対象とします。準備PR #1003の必須CI成功・main merge後に公開しました。公開EditorはSB3内のruntimeを読み込みます。Docs/Samplesも同じ公開版へ揃えます。

**この版はnpmへ公開しません。** npm CLI/APIは公開済みrc.46です。rc.48のCLIが必要な場合は公開tagを固定してソースからbuild:libしてください。未公開npm版をインストール可能として案内しません。

Appの依存/lockと生成runtimeのKVSは公開済み0.2.0のままです。未公開KVS内部修正は同梱しません。KVS配布・App依存更新・通常npm依存での接続検証は別残務です。#775/#780全体や物理カメラ/OS/native OPFS・全外側ownerの解放保証の完了を意味しません。進行中の別作業は含めません。
