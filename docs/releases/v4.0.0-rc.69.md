# v4.0.0-rc.69

## 台本編集ブロックのアイコンを統一

Kamishibai Block Scriptの共通アイコンを、白い紙に横棒3本の「台本」アイコンへ変更します。`kamishibai`、`kamishibaiConfig`、`includeBlocks`、「この部分を使う」、条件分岐・反復・参照・変数・比較・論理式など、台本を構成するブロックが対象です。

個別に指定されたフォーム用アイコンは優先して保持し、再生用Runtimeのアイコンは維持します。opcode・引数・接続・保存データ・台本の意味・既存feature flagの条件は変更しません。

既存SB3に埋め込まれた拡張は自動更新されません。元の台本・SB3を残し、この版のCLIとランタイムで再生成してください。公式Samplesも公開版へ追従して再生成します。
