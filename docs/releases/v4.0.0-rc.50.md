# v4.0.0-rc.50

DSL 4.0のプレリリース改訂です。PR #1014〜#1020と、追加承認されたPR #1021を含みます。DSLは4.0のままで、新しい有効化スイッチは追加しません。

## 変更内容

- 共有Object URL owner、素材のmaterialization保持予算/LRU、共通UI画像の章をまたぐ寿命とpublication読込時の常駐予算（#1014・#1016・#1017）。
- 次章のremote動画を検証済みcacheへ先読みし、遷移失敗・cancel時には現章の再生を保持（#1015）。
- publicationの章間で素材ファイルを一度だけ保存する重複排除（#1018）。
- compiled配布profileの追加（#1019）。
- Camera Source 0.19.2のstream解放修正とTeachable Machine 3.5.5を生成runtimeへ反映（#1020・#1021）。

## 公開範囲・検証

GitHub prerelease・版付きStandard SB3・Pages Player・公開Editorでの読込、およびDocs/Samplesへの追従を対象とします。npm rc.50は公開しません。npmの既公開版はrc.49のままです。CLIで本版を使う場合は公開tagからbuildし、rc.50のSB3と組み合わせてください。

```sh
git clone --branch v4.0.0-rc.50 --depth 1 https://github.com/kubohiroya/turbowarp-kamishibai-app.git .tools/kamishibai-rc50
pnpm --dir .tools/kamishibai-rc50 install --frozen-lockfile
pnpm --dir .tools/kamishibai-rc50 run build:lib
node .tools/kamishibai-rc50/bin/turbowarp-kamishibai.mjs --help
```

各実装PRのCI成功を前提に、版・fingerprint・凍結snapshot・関連資源管理/compiled配布の境界を対象検証します。公開後にChrome/Edgeで未改変配布SB3・Playerと公開Editorを確認します。Firefoxはメジャーリリース時のみ、Safari対象外です。新しい実聴や物理メモリ回収の証明とは扱いません。版・fingerprint・release/配布契約と関連資源管理/compiled配布の10ファイル96テスト、型検査・対象lint/format、再構築snapshot照合が成功しました。検証・公開結果はIssue #1022へ記録します。
