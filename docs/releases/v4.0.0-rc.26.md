## 対象と変更

公開CLIの実行時依存に`ajv@8.20.0`を追加しました（[#914](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/914)）。新規導入時に`ajv/dist/2020.js`が見つからず、CLI起動・台本書き出し・検査が停止する問題を修正します。利用側でAjvを手動追加する必要はありません。
配布検証も開発用node_modulesへのリンクを使わず、tarballを新規フォルダーに`--omit=dev`で導入し、公開API・CLI起動・正常/不正DSLの検査を確認します。

rc.25以降にmainへ入った次の修正を含みます。

- 「この部分を使う」でOFFにした台本範囲を見分けやすくしました（[#909](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/909)）。機能フラグ`sourceSections`は既定OFFを維持します。
- カメラプレビューの操作を設定メニューにまとめ、ツールバーとの重なりを解消しました（[#910](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/910)）。
- タイトル操作ボタンをEditorの編集ダイアログ背景より下へ配置しました（[#912](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/912)）。
- `say`・`think`の`SPEC`に専用フォームを登録しました（[#915](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/915)）。

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- CLI・開発環境はNode.js 24.0.0以上です。
- Schema・依存拡張の版はrc.25から変更しません。
- 既存SB3の埋込runtimeは自動更新されません。runtimeの修正にはrc.26でSB3を再生成してください。
- 公開済みrc.23・rc.25は差し替えません。旧版を継続利用する場合のAjv追加導入手順は[公開ガイド](https://kubohiroya.github.io/turbowarp-kamishibai-docs/4.0/dsl-author-guides/dsl-4.0-block-script-conversion-guide/#cli-ajv-workaround)にあります。
