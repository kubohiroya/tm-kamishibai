## 対象と変更

ブロック台本の非対応ブロック診断を改善しました（[#932](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/932)）。エラー画面にブロックの表示名とステージ／スプライト名を表示し、「該当ブロックを表示」からコードタブ・対象へ切り替え、折りたたまれた親を展開してブロックを選択・中央表示します。日本語環境では制御ブロックの日本語名を表示します。

削除・置換・作品切替・新しい診断への差し替えが発生した場合の誤移動を防ぎます。定義が取得できないブロックの表示名は内部opcodeへフォールバックし、Blocklyを提供しないプレイヤーでは移動ボタンを表示しません。エラーパネルを閉じても台本の実行は再開しません。

rc.27以降のscene設定フォーム（[#926](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/926)）と、タイトル・メニュー名の「TurboWarp紙芝居」への統一（[#929](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/929)）も収録します。

mainへ統合済みの組み込み拡張セキュリティ情報の保持（[#930](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/930)）も収録します。ブロック台本生成時に名前・権限情報がラッパーの前に残る修正です。Standard SB3の凍結内容は変更しません。

## 互換性

- DSL document versionは文字列`kamishibai: "4.0"`を維持します。制御構造などの非対応opcodeを許可する変更はありません。
- CLI・開発環境はNode.js 24.0.0以上です。既存の機能フラグは既定値を維持します。
- 既存SB3の組み込みruntimeは自動更新されません。診断改善を利用するブロック台本SB3は本版のauthoring runtimeで再生成してください。
- npmは`next`・`latest`で配布し、Pagesの推奨安定版は`3.2.3`を維持します。
