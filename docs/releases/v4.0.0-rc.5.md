## 概要

v4.0.0-rc.5は、DSL 4.0の全23 core actionをTurboWarp blockとして公開し、YAML台本と
TurboWarpコードのどちらからも同じActionContextを通じて実行できるようにする公開候補です。
rc.4で導入した機能拡張ごとのブロックアイコンを維持しながら、runtime JavaScriptからPoseNet model dataを
分離し、TM 1.10.0の中断可能なモデル初期化を選択できるようにします。

安定版としての推奨は3.2.3を維持し、4.0.0-rc.5は4.0正式公開前の検証に使用します。

## rc.4からの主な変更

- manifestに定義した全23 core actionを、`kubohiroyakamishibai4`の可視TurboWarp blockとして公開
- TurboWarp blockからの呼び出しを、YAML台本と同じregistry、Schema正規化、ActionContext、
  lifecycleへ接続
- Asset Manager、Async Input、Bubble、Runtime Expression、SVG Text、TMの
  member由来`blockIconURI`を引き続き通常blockへ継承
- TurboWarp Editorの7つのmember見出し直後から、core Runtimeのblock referenceまたは
  各上流機能拡張のGitHub Pagesを開けるdocumentation buttonを追加
- Bubbleを0.7.0へ更新し、実測幅による折り返し、native reveal、音声、表示animationをDSLから利用可能にする
- TMを1.10.0へ更新し、`poseRecognition.modelInitialization`で`legacy`／`latest-needed`と
  並列初期化を設定可能にする。既定値は従来互換の`legacy`／`parallel: false`
- モデル準備のAbortSignalをTM compositionへ渡し、不要になった初期化を安全に中断可能にする
- PoseNet model dataをruntime JavaScriptのBase64から明示的なproject model dataへ移し、
  playback runtimeをauthoring runtimeから分離
- 配布SB3を7,866,652 bytesから6,664,571 bytesへ削減

## 互換性と制約

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- package、Standard Runtime reporter、artifact metadataは`4.0.0-rc.5`に揃います。
- 既定のモデル初期化はrc.4以前と同じ直列の`legacy`です。問題時は台本設定を
  `policy: legacy`、`parallel: false`へ戻せます。
- Structured Data Standalone／DebugとAction Contextは既定OFFのままです。
- 配布SB3は外部CDNなしでPoseNet model dataを復元できます。
- rc.4以前のSB3は埋め込み済みの旧Runtimeをそのまま保持し、rc.5のbundle sourceへ差し替えません。
- 3.1／3.2作品はversion 3.2.3の配布SB3で継続利用できます。
