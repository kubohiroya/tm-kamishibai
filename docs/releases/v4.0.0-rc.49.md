# v4.0.0-rc.49

DSL 4.0のプレリリースです。公開済みKVS 0.2.1へ依存を固定し、解放失敗後の明示再試行を通常npm経路とStandard SB3へ反映します。PR #1006の依存/lock・runtime再生成・接続回帰、PR #1005の実聴確認ツールのキー所有権修正を含みます。DSLは4.0のままで、追加のURLスイッチはありません。

## 変更内容

- KVSのdirect/IDB sessionが解放失敗時のownerと未削除レコードを保持し、明示disposeで再試行します。通常readは閉じたまま、他sessionを保持し、成功済みownerは再解放しません。
- Appの依存・lock・pin・runtime出典を0.2.1へ揃え、生成runtime3種へ組み込みます。ソースalias/skipを撤去した接続回帰は通常CIで実行します。
- 実聴確認ツールはfocus移動後もパネル始点のEnter解放を隔離し、ホスト始点のキー所有権を奪いません。

## 公開範囲と検証

npm public/next・latest、GitHub prerelease/版付きStandard SB3、Pages Playerを対象とします。rc.47/rc.48はnpm未公開でしたが、今回はnpmとSB3をrc.49へ揃えます。公開後に実物のhashと版・依存を照合しました。

PR #1006のCI 1,641件、関連回帰171件＋pin/出典2件、生成runtime一致・profile2件、Chrome native IndexedDB 1件2条件の成功を前提とします。今回の版更新・fingerprint・release/配布契約と生成物の56テスト、型・対象静的検証、準備PRの通常CI 1,641テストが成功。Chrome/Edgeの公開Editor・Player・Packagerで起動・タイトル・操作を確認しました。Firefoxはメジャーリリース時のみ、Safari対象外です。

## 残務とロールバック

session成立前の部分作成/cleanup失敗、publicationの外側owner、下位OPFS資源、全体budget/LRUと全物理資源回収、#771・#779は継続します。IDBの削除確認を動画実聴や物理メモリ回収の証明としません。#775/#780全体はOpenを維持します。

問題時はSB3/Player導線を固定rc.48へ戻し、npmは公開済みrc.46も使用可能です。公開済み同版のtag・SB3・Playerは上書きせず次RCで修正します。sourceは今回の版更新・公開記録の差分を一式で戻します。安定版3.2.3と過去版を保持します。
