# 4.0.0-rc.71 — 実行エラーの原因・発生箇所・対処を表示

紙芝居が停止した際に、利用者が次の操作を判断できるエラー画面へ改善します。関連: [Issue #1094](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1094)。DSLの版は4.0のままです。

## 変更内容

- 原因、停止した場面・命令、影響、対処を日本語／英語で表示し、技術詳細と周辺ソースは折りたたみます。診断情報をコピーでき、メニューへ戻る操作で壊れた台本を再実行しません。
- 台本の元ソースとブロックIDを保持し、`includeBlocks`と`kamishibaiConfig`が併用された際に別のブロックを強調する不具合を修正します。異なるスプライト間で同じIDがある場合も区別し、編集・置換された古いブロックへの移動を避けます。
- JSON Schemaの検証詳細を任意の診断属性として保持します。`oneOf`／`anyOf`の候補条件を必須の修正内容と誤案内せず、既存の診断コードとの互換性を維持します。
- 元例外と後処理の例外を区別し、診断に含めるURL認証情報や秘密値を伏せます。小さいステージ、キーボード操作、コピーできない環境にも対応します。

新画面は既定で有効です。切替フラグは追加しません。既存SB3の埋込ランタイムは自動更新されないため、この版のCLI・ランタイムで再生成してください。設計・診断の扱いは[実行エラー表示](../dsl4-runtime-errors.md)に記載しています。
