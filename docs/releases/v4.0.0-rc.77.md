# 4.0.0-rc.77 — ブロックアイコンのプレビューと配置編集

関連: [Issue #1100](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1100)。DSLは`4.0`を維持する。rc.76以前の凍結済み・公開済み成果物は変更しない。

## 操作と有効化

対応するTurboWarp Plus EditorのURLへ`twPlusBlockPreview=1`を指定して起動する。既定OFFで、読み込み前の`globalThis.TW_BLOCK_ICON_PREVIEWS === true`でも有効化できる。作品データや起動後の変更では切り替わらない。

- scene内actionのアイコンをホバーすると、その時点の背景・アクター・吹き出しを静止表示する。
- sceneのアイコンをクリックすると、その場面を再生する。
- show actorの本体をドラッグして座標、枠のふちをドラッグしてスケールを設定する。setSkinもスケール変更に対応する。
- moveToの座標・時間・イージング、say/thinkの文章・時間・スタイルを変更すると、その場で下書きのアニメーションを再生し直す。
- 保存・Cancel・Undo/Redoは共通フォームと同じトランザクションで扱う。元ステージは保存前に変更しない。

moveToのDSLにスケール引数はないため、拡縮はshow/setSkinで指定する。人の入力や独自アクションの結果が必要な経路は理由を表示する。

文章と秒数を直接持つsayText/thinkTextのブロックも、固定入力フォームを変更すると即時に再生する。JSON設定を持つsay/thinkと、それぞれのブロック引数を保ったまま同じBubble実行経路を使用する。

## 依存と隔離

[Data Editor #94](https://github.com/kubohiroya/turbowarp-extension-data-editor/pull/94)のpreview APIを組み込んだ、[scratch-gui #79](https://github.com/kubohiroya/scratch-gui/pull/79)対応Editorが必要となる。APIがないEditorでは従来フォームを使用する。対応版のnpm公開やEditor配信は、このPR作成には含めない。

プレビューは独立VMで再生し、共有dispatchの登録先と元VMの購読を保持する。[Asset Cache #32](https://github.com/kubohiroya/turbowarp-asset-cache/pull/32)と同じruntime注入・購読解放を、Appの固定依存0.6.0へのpnpm patchで追跡する。依存の対応版へ移す際は、同じ隔離検証を維持してpatch・workspace指定・lockを一組で外す。

吹き出し内部名に含まれていたNULを取り除き、SVGで有効な内部名を使う。作者が指定したスタイルIDと保存形式は維持する。

## 再生成・切戻し・公開状態

旧作業treeのTeachable Machine 3.5.6参照は、実際に公開される`dist/tm.js`へ修正した。PRは最新mainの4.1.0を使い、同版の公開exportである`dist/teachable-machine.js`と`dist/teachable-machine-webgpu.js`を維持する。一時的なNode解決hookは使わない。

ローカルのrc.77候補を新しく生成・凍結し、既存rc.76のmetadataを保持する。この変更のpush・PR作成はレビュー用であり、Release・npm・Pagesへの公開ではない。

切戻しは起動URLの`twPlusBlockPreview=1`と起動前global指定を外してEditorを再読み込みする。コードを戻す場合は関連PRをrevertし、元のYAMLから別版の編集用SB3を再生成する。同じ公開版の成果物を差し替えない。

操作・設計・検証証跡は[設計書](../design/dsl-4-block-icon-preview.md)を参照。
