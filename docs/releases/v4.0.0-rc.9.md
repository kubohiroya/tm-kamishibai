## 概要

v4.0.0-rc.9は、scene、背景、actorのskin／表示、BGMに共通のcrossfade transitionを追加し、
公式Standard production／non-embedded development profileで既定ONにする公開候補です。
BGMは`@kubohiroya/turbowarp-asset-manager@0.13.0`の再生instance単位voice／gain APIを使用します。

## rc.8からの主な変更

- `presentation.transitions`へ`scene`、`backdrop`、`actorSkin`、`actorVisibility`を追加
- `audio.bgm.transition`とaction／scene単位の`transition`上書きを追加
- visual transitionへ`linear`／`easeInOut`、BGMへ`linear`／`equalPower`を追加
- scene frame capture、背景／actorの一時drawable、actor visibility補間を実装
- BGMを単一logical channelとしてvoice管理し、cutとcrossfadeを同じ経路へ統合
- `restart`、same-asset no-op、asset retention、stop／skip／dispose時のcleanupを固定
- Asset Managerを0.11.0から0.13.0へexact pin
- Standard profileではcrossfadeを既定ON、汎用default flagsではOFFのまま維持
- 日英READMEへ指定例、互換性、rollbackを追加

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- scene、背景、actor skin／visibility、BGMの組み込みtransition既定値はすべて`cut`（0秒）です。
- transitionを指定しないrc.8以前のDSL 4台本は、表示、音声、timingを変更せず実行します。
- 低レベルhostは`dsl4CrossfadeTransitions: false`を明示してrollbackできます。
- flag OFFでcrossfade構文が残る場合は、暗黙にcutへ落とさず`K4-TRANSITION-FLAG-001`で実行前に拒否します。
- sceneの組み込み既定を0.5秒などへ変更せず、作品が秒数を明示した場合だけcrossfadeします。

## ロールバック

rc.9を同じversionで差し替えません。問題時は公開済みrc.8を利用し、修正はrc.10として公開します。
Standard runtimeだけを切り戻す場合は`dsl4CrossfadeTransitions: false`を明示してbundleを再生成し、
台本のcrossfade指定を`cut`へ戻すか削除します。安定版の推奨は引き続き3.2.3です。
