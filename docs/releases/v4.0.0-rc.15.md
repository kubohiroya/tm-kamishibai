# turbowarp-kamishibai-app v4.0.0-rc.15

Copyright © 2026 Hiroya Kubo.

## 対象

- 埋め込みTeachable Machine拡張の依存を、改名後の`@kubohiroya/turbowarp-teachable-machine@3.3.0`へ移行

## 概要

v4.0.0-rc.15は、上流の改名に追随するためのcandidateです。`@kubohiroya/turbowarp-tm`は
`Moved-to-@kubohiroya/turbowarp-teachable-machine`としてdeprecatedになったため、依存を改名後の
packageへ移し、同時に現行の`3.3.0`へ上げます。

runtimeとDSLの意味は変わりません。rc.14から変わるのは、埋め込む拡張のbundleのバイト列と、
package名・repository URL・docs URLを指す文字列だけです。

## 上流の改名について

改名は内容の変更を伴いました。旧`@kubohiroya/turbowarp-tm@3.2.0`と改名後の同version
`@kubohiroya/turbowarp-teachable-machine@3.2.0`を比べると、ファイル構成は同じですが、
`dist/tm.js`、`dist/composition.js`、`dist/posenet.js`、`dist/runtime.js`、
`dist/backend-wasm.js`、`dist/backend-webgpu.js`が違います。差は次の2つでした。

- bundlerの出力形が変わった再ビルド（`dist/tm.js`は73,216 bytesから69,212 bytesへ）
- 名称文字列（`DOCS_URI`が`https://kubohiroya.github.io/turbowarp-teachable-machine/`へ）

**公開面は一致しています。** block surfaceは48 opcodeで完全一致、Extension IDは`kubohiroyatm`の
まま、PoseNetの重みシャードとmodel JSONはバイト一致、`dist/types/*.d.ts`の差は上記の`DOCS_URI`と
doc commentの文言だけです。

`3.3.0`は`3.2.0`（改名後）に対して`.d.ts`が全て一致、opcodeも48で一致、PoseNetの重みも一致で、
JS bundleだけが違います。上流のrelease noteによれば`3.2.1`はversion番号のみ、`3.3.0`は
repository scriptのTypeScript移行とrelease準備です。つまりbundleの差はビルド経路の変更によるもので、
runtimeの挙動を変えるものではありません。

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- Extension IDは`kubohiroyatm`のままなので、rc.14以前のStandard SB3で作った作品はそのまま開けます。
- block surfaceとcomposition APIは変わりません。
- 旧package名`@kubohiroya/turbowarp-tm`は過去releaseとmigration noteにだけ残ります。
- rc.12以降、say／thinkはTurboWarp BubbleのSVG overlayに描画され、`Scratch.looks`には書き込みません。
- 3.1／3.2作品は推奨安定版3.2.3で継続利用できます。

### 下流への影響

Standard SB3のバイト列が変わるため、公開済みartifactをベースとして固定している下流は再pinが必要です。
turbowarp-kamishibai-samplesは`stories/urashima/dsl4-build.config.json`の`runtime`で固定しています。

## ロールバック

rc.15を同じversionで差し替えません。問題時は公開済みrc.14、rc.13、または安定版3.2.3を利用し、修正は次の
candidateとして公開します。npm dist-tag、download catalog、Pagesの推奨表示だけを直前の検証済み組へ
戻し、公開済みSB3、release metadata、旧URL、旧packageの履歴は削除しません。
