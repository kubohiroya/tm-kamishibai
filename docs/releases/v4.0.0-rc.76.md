# v4.0.0-rc.76 — 不要なfile素材payloadの除去

## 変更

他のfile素材が残っている作品で、file素材を台本から削除したり、project/remote素材へ切り替えたりすると、旧payloadがbundleへ残り、起動前に`Unexpected payload`または`Unexpected file`となる問題（#1096）を修正します。

元bundleの整合性を検証してから、現在のmanifestが必要とするasset IDとlogical pathの組だけを保持します。破損したbundleを再署名せず、新規file素材の不足やinputPath変更も引き続き拒否します。embedded-base64、binary-entry v2/v3、bundled/unbundledの保存channelを対象とし、共有entryを使う現行素材を保持します。明示素材とimplicit project素材の照合規則は変更しません。

## 互換性と検証

台本ブロック・衣装・背景・音・無関係なproject情報は変更しません。元作品のbytesを保持し、正式prepare/loadと別名保存後の再読込を検証しています。回帰は素材の削除、project/remote化、空manifest、元payloadの改ざん・不足、素材ID/pathの境界を含みます。実カメラによる認識精度の検証とは区別します。

## 公開状態

この版はCIで修正sourceと配布snapshotを照合するための未公開候補です。凍結rc.75のmetadata・配布物は保持します。tag、GitHub Release、npm、Pagesの公開はこの変更に含みません。公開済みの導入例はrc.75を保持します。

既存SB3の埋込runtimeは自動更新されません。この修正を利用者へ配布するには、別途承認したrc.76の公開と作品runtimeの更新が必要です。新しい成果物を使う場合も元作品を保存してください。

## ロールバック

本体修正を戻し、対応する未公開候補を使用しない状態へ戻します。作品は保持した元SB3へ戻します。公開済み版や凍結済みsnapshotを上書きしません。
