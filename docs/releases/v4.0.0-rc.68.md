# 4.0.0-rc.68 — 台本編集ブロックの識別アイコン

- 台本編集用拡張の共通blockIconURIに、既存の紙芝居アイコンを指定します。「この部分を使う」「action options」、条件分岐・反復・参照・変数・比較・論理式等をTurboWarp標準ブロックと区別しやすくします。
- scene・定義・一覧・条件の一覧など、個別フォームを持つブロックのアイコンを優先して保持します。opcode・入力・接続・台本の意味・既存feature flagの条件は変更しません。
- 3種類の生成runtimeを更新し、凍結済みrc.67のmetadataと候補SB3を保持します。既存SB3の拡張は自動更新されないため、修正を含むCLIとruntimeで再生成します。

## 検証

既存のブロック台本生成・読戻し・narrative互換性50テストと生成物決定性1テストが成功しました。TurboWarp Editorで自作パレット25ブロックと画像対象11ブロックのworkspace描画を確認し、フォーム用アイコンと標準ブロックの表示が維持されることを確認しています。型検証・lint・formatも成功しています。

新規rc.68スナップショットを既存cut手順で凍結し、source identity・SB3のハッシュを再ビルドで照合します。CI結果とPRリンクはIssue #1087へ記録します。

## 公開結果

- GitHub Release・Pages: 未公開。作成・配信は別途承認後に行います。
- npm: 公開後に記録。

## ロールバック

共通アイコン指定と生成物の変更を戻します。既存の台本・ブロック保存形式の移行は不要です。凍結済み／公開済み版を上書きせず、公開後の修正は新しい版で行います。
