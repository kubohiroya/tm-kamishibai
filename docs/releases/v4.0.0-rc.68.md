## 定義監査と宣言省略

- `audit-dsl4-definitions`でasset・actor・control・cover・recognition・textStyle・variable・loading・navigationの定義と参照を検査します。未使用は警告、未定義参照や不正値はエラーです。既定は読取のみで、未使用と確定した定義の削除は明示オプションによる別出力です。元の作品・素材を保持します。使い方と削除の制約は[定義監査ガイド](../dsl4-definition-audit.md)を参照してください。
- ツールチェインとランタイムの双方で、SB3内の背景・音・衣装をasset宣言なしで実名参照できます。背景はStage、衣装は対象actorのスプライト内で解決します。音はStageを優先し、Stageになければ一意なスプライトの音を使います。存在しない名前・曖昧な名前は診断します。
- 未宣言actorは完全に同名のスプライトを使い、その最初の衣装を初期値にします。明示actorでは従来のactorNameによる対応を優先します。actor名には既存の識別子制約があり、空白を含むスプライト名はそのまま使えません。
- 未宣言coverはStageの最初の背景と音を使います。音がなければBGMを省き、背景がなければ表紙を作りません。明示coverを優先し、そこにbgmを書かなければBGMを追加しません。
- 未宣言の`variables.startSceneIndex`は1を補います。これは作品変数の初期値であり、開始シーンを切り替える指定ではありません。

明示値と必要な設定は保持します。不正なassets／actors宣言を省略扱いで修復しません。file・remote素材、別名、独自初期値、control・recognition等の設定は用途に応じて宣言します。暗黙素材・既定値に新しい有効化フラグはありません。

対応ランタイムが既存のsource作品・compiled作品を読む場合にも既定coverを補うため、従来coverがなかった作品で表紙や音が増える場合があります。既存compiledの署名対象データを保持して検証した後に既定値を補います。表紙の背景・音を選びたい場合はcoverを明示してください。

## JSON不要のsay/think

- `actor [TARGET] say text [TEXT] seconds [SECONDS]`
- `actor [TARGET] think text [TEXT] seconds [SECONDS]`

TEXTは普通の文字列、SECONDSは0以上の秒数です。既存のsay/thinkと同じ命令へ正規化し、Schema検証・YAML往復・実行処理を共有します。textとsecondsだけの命令は、対応能力を示すベースのランタイムでは簡易版に変換します。旧ランタイムを含むベースでは既存SPEC版を維持し、入力待ち・装飾・効果音・stableId等の指定もSPEC版を保持します。

宣言省略には対応するCLIと埋込ランタイムを揃えてください。既存SB3の拡張は自動更新されないため、元のYAML・SB3を残し、この版のCLI／ランタイムで再生成します。

## 台本編集ブロックの識別アイコン

台本編集用拡張の共通blockIconURIに既存の紙芝居アイコンを指定し、「この部分を使う」「action options」、条件分岐・反復・参照・変数・比較・論理式等をTurboWarp標準ブロックと区別しやすくします。scene・定義・一覧・条件の一覧など、個別フォーム用アイコンを優先して保持します。このアイコン修正はopcode・入力・接続・台本の意味・既存feature flagの条件を変更しません。
