# 4.0.0-rc.79 — 作品内の登場人物・素材を使うタイトルカメラ判定

関連: [App #1104](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1104)。DSLは`4.0`、Camera Sourceは`0.22.1`を維持する。公開済みrc.78以前のmetadata・tag・配布物は変更しない。

## 修正範囲

登場人物・背景・衣装・音をScratch作品から暗黙に解決する台本では、タイトルのカメラ表示判定だけが作品の情報を渡していなかった。このため、ポーズを含む正当な台本も参照エラーとなり、タイトル上の共通「カメラ」入口が表示されなかった。再生開始後のカメラ操作は別の正規読込経路を使い、従来どおり表示されていた。

タイトル判定にも共有frontendの正規`parse(source, {project})`を使う。runtime hostの公開target APIから登場人物名・衣装/音の名前・actorNameのスカラー変数だけを取得し、実体の素材やブロック・拡張URL・全SB3を複製しない。cloneを参照候補に含めず、参照不足・重複・不正な台本には引き続き入口を表示しない。原文に定義がそろった作品も従来どおり判定する。

[rc.78](v4.0.0-rc.78.md)の依存初期化・作品読込後の再接続、世代管理、失敗時の予備UI、Camera Sourceの許可とstream/lease所有権、[rc.77](v4.0.0-rc.77.md)の既定OFFプレビューとAsset Cache隔離patchを維持する。許可の自動承認・代理クリックは追加しない。

## 検証・公開・切戻し

自己完結原文、作品からの暗黙参照、参照不足・重複、clone除外と、既存の接続/lifecycle境界を対象テストで確認する。正式tutorialの原文・素材・台本ブロックを保持した別のローカル作品で、タイトルの共通入口、パネル、停止・再開始を確認してから新候補を凍結する。実機カメラ取得や認識精度は測定しない。

公式driverによるrc.79の生成・凍結と公開後のhash照合を分け、候補の存在だけで公開完了を主張しない。切戻しは保持した元作品とrc.78へ戻す。既存版を上書きせず、修正が必要なら次のrcを作成する。
