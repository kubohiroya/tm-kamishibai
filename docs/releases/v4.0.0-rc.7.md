## 概要

v4.0.0-rc.7は、`@kubohiroya/turbowarp-tmpose@1.12.0`をexact pinし、TMPoseの公開APIと
ブロック文をrecognition用語へ統一する公開候補です。TMPose 1.12.0のGitHub Release、npm package、
Pagesを確認してから、この下流更新を再生成しました。

## rc.6からの主な変更

- TMPoseを1.11.0から1.12.0へexact pin
- `startPredict`を`startRecognition`へ変更
- `stopPredict`を`stopRecognition`へ変更
- `isPredicting`を`isRecognizing`へ変更
- `firstPredictMsReporter`を`firstRecognitionMsReporter`へ変更
- 旧opcodeの互換aliasを追加せず、配布bundleとtestから除外
- accumulated pose eventをversion 2へ上げ、reasonを`prediction`から`recognition`へ変更

ブロックに表示される文言は以前から`start recognition`、`stop recognition`、
`recognition is running?`、`first recognition time (ms)`だったため、見た目と役割は変わりません。
保存されるopcodeだけが新しいrecognition名になります。

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- DSL Schema、`poseRecognition`設定、Composition API、overlay設定は変わりません。
- rc.6以前に旧TMPose opcodeを保存した手書きTurboWarp scriptは自動移行しません。rc.7パレットで
  対応blockを組み直してください。
- Standard SB3自体のDSL runtimeはComposition APIを利用するため、通常のYAML台本に変更は不要です。
