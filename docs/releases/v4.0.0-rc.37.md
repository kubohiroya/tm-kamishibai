## 変更

DSL 4.0に、ID付きの矩形領域を表示する `video` と、IDを指定して操作する `videoControl` を追加しました。MP4/WebMアセットとHTTP(S)の動画ファイルURLに対応します。台本は `kamishibai: '4.0'` のままです。

- 再生終了まで待つ、バックグラウンドで1回再生、ループ、停止、一時停止・再開、シーク、音量・消音・速度を指定できます。
- `plane: front` はステージ前面、`plane: background` は背景の上・スプライトの下に表示します。同じplaneでは `zIndex` が大きい動画を手前に置きます。
- シーン切替、終了・失敗・停止、タイトルへ戻る操作で領域と再生リソースを解放します。

npmとStandard SB3を同じrc.36として公開します。npm未公開だったrc.28〜rc.34の変更も含み、Camera Source 0.18.0、sb3-toolchain 0.16.0を固定します。安定版の推奨は3.2.3を維持します。

## 動画は標準で利用できます

Standard SB3のEditor / Player / Packagerと制作プレビューでは、URLパラメータなしで動画を利用できます。有効化用URLスイッチはありません。
npm APIで独自hostを構成する場合は既存のStandard featureFlagsを使います。runtime全体を明示構成する低水準APIの契約は維持します。

```yaml
kamishibai: '4.0'
controls:
  keymaps:
    production:
      Space: navigation.nextAction
assets:
  OpeningMovie:
    kind: video
    file: assets/opening.webm
scenes:
  opening:
    - video:
        id: movie
        asset: OpeningMovie
        x: 0
        y: 0
        width: 320
        height: 180
        plane: front
        zIndex: 10
        muted: true
    - videoControl: {id: movie, operation: playUntilDone}
```

操作の詳細は[動画再生の設計・利用説明](../design/dsl-4-video.md)を参照してください。

## 制約

音声付き動画はブラウザのautoplay制限で開始を拒否される場合があります。コーデックの対応もブラウザに従います。背景planeの別オリジンURLにはCORS許可が必要で、textureの辺長は最大2048です。オフライン配布には埋め込み動画アセットを使ってください。

任意のスプライト間への動画配置、保存データへの接続、asset group・可変viewport・segment prefetchとの統合、各実画面と音声付き動画の全ブラウザ検証は引き続き [#780](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/780) の残りの範囲です。

## ロールバック
