# v4.0.0-rc.46 — publication保存バーの重なり修正

## 変更内容

- PR #993の保存バー修正を含むDSL 4.0プレリリースです。Editor / Player / Packagerで、保存・診断バーをstageとは別の行へ配置します。
- stageは残りの領域へ4:3で配置し、canvas・動画overlay・背景plane・pointer targetの表示座標を揃えます。resize、mouse/Enter/Spaceでの保存、自然終了後のメニュー表示と再開に対応します。
- rc.44でStandardになった有限反復・条件分岐・型付き参照も含め、npmとSB3の公開対象を揃えます。DSLは4.0を維持します。
