## 対象と変更

非対応ブロックへの移動後に、対象の周囲へ黄色いグローを表示します。公開エディターではBlocklyの選択クラスに見える輪郭がなかったため、選択と中央表示だけでは強調にならない問題を修正しました。SVGフィルターのIDやエディターの選択テーマへ依存しない一時的なCSS shadowを使います。

次の診断・再実行時は自身のshadowだけを解除し、元のfilterと優先度を復元します。別の処理がfilterを変更していた場合は上書きしません。台本・素材は変更せず、ブロックの実行や制御構造のサポートを追加する変更でもありません。

rc.29の日本語ブロック名・ステージ／スプライト名、コードタブ／対象切替・親展開、TurboWarp JSON保存時のblockId保持も収録します。既存SB3は自動更新されないため、本版のauthoring runtimeで再生成してください。rc.28は未公開、rc.29はGitHubのみ公開した候補として保持し、両版のnpm公開は行いません。

## 互換性と配布

- DSL document versionは`4.0`、既存flagの既定値は維持します。
- Node.js 24以上。npmはnext/latestへ公開し、推奨安定版3.2.3は維持します。
- samplesの編集用runtimeと6SB3を更新し、再生用rc.25 pin・台本YAML・素材は保持します。
