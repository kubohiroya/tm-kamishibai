# v4.0.0-rc.53

Camera Source・Asset Cache・Bubbleの配布JavaScriptに、サンドボックス外での実行が必須である宣言を追加した版へ更新しました。共通セキュリティダイアログで、動作しない「サンドボックスあり」を無効化し、その理由と「動作に必要」を日本語・英語で表示できるようにします。実行はユーザーの明示的な許可後に開始します。

## 依存更新

- Camera Source: 0.19.3
- Asset Cache: 0.3.1
- Async Input: 0.8.1
- Bubble: 0.13.4
- Teachable Machine: 3.5.6

公開元は、起動失敗・破棄時の資源解放を修正したPR #1033とPR #1031（sealed複数章保存・読込）までを統合したmainです。rc.51以前の公開物と凍結記録は保持しています。

## 検証と切戻し

上流の公開tarballと公開元を照合し、候補SB3を再生成して凍結します。公開Editorでは日英の必須表示・無効化理由・明示許可後の起動を確認します。結果はIssue #1034へ記録します。

問題がある場合は依存pinと配布リンクを直前の検証済み版へ戻し、今回の変更をrevertします。
