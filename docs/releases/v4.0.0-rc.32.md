## 対象と変更

生成SB3をTurboWarp Editorで読み込んだ際、ツールボックスXMLの生成で`Unexpected input recieved in replaceUnsafeChars`が出る問題を修正します。同梱拡張のカテゴリ情報に`color1`だけがあり、未定義の`color2`がXMLへ渡されることが原因でした。

`@kubohiroya/sb3-toolchain@0.15.0`へpnpmパッチを適用し、通常bundleとサンドボックス案内の両方に`color2`・`color3`を設定します。主色は保持します。playback runtimeも再生成します。

凍結済みrc.30の成果物・metadataは保持し、本修正を新しいrc.32候補として凍結します。既存SB3への反映には再生成が必要です。DSL document versionは`4.0`、既存feature flagの既定値と推奨安定版3.2.3は維持します。
