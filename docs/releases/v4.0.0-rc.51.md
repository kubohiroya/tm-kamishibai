# v4.0.0-rc.51

DSL 4.0のプレリリース改訂です。PR #1024・#1026・#1027・#1028を含みます。進行中のcreation cleanup作業は含めません。

## 変更内容

- Standardアプリのメニューとpublicationの保存UIから、YAMLを含めず検証済みStory IRを保存するcompiled配布を選べます（#1024）。compiledは暗号化ではありません。
- 台本・素材をパスワード鍵で暗号化するsealed配布profileを追加します（#1026）。CLIから生成し、受け取った人へパスワードを別途伝えます。
- Standardアプリでsealed作品を開くと、日本語/英語のパスワード入力画面を表示します。誤入力の再試行、キャンセル、ページ内の再起動時の再利用に対応します（#1028）。
- publicationの解放失敗時にcleanup ownerを保持し、disposeの再試行を直列化します（#1027）。

## 公開範囲・検証

GitHub prerelease・版付きStandard SB3・Pages Player・公開Editorでの読込、およびDocs/Samplesの追従を対象とします。npm rc.51は公開しません。npmの既公開版はrc.49のままです。CLIで本版を使う場合は公開tagからbuildし、rc.51のSB3と組み合わせてください。

```sh
git clone --branch v4.0.0-rc.51 --depth 1 https://github.com/kubohiroya/turbowarp-kamishibai-app.git .tools/kamishibai-rc51
pnpm --dir .tools/kamishibai-rc51 install --frozen-lockfile
pnpm --dir .tools/kamishibai-rc51 run build:lib
node .tools/kamishibai-rc51/bin/turbowarp-kamishibai.mjs --help
```

各実装PRのCIを前提に、版・fingerprint・凍結snapshot・compiled保存・sealed復号/パスワード入力・publication cleanupの変更境界を検証します。公開後にChrome/Edgeで配布SB3・Player・公開Editorを確認し、検証結果をIssue #1029へ記録します。Firefoxはメジャーリリース時のみ、Safari対象外です。新しい実聴や物理メモリ回収の証明とは扱いません。
