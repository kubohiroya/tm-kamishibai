## 変更

カメラと台本の自動リロードを、Editorでは停止ボタンの後ろに表示します。カメラは1つの入口から未起動時の許可・開始と、起動後のカメラ選択・ミラーリング設定を開きます。リロードはYAML台本を開いて物語を動作させている間だけ表示し、タイトルへ戻ると隠します。

TurboWarp Packagerで書き出したHTMLでは、Editorの上部メニューに依存しない共通Dockへ同じ操作を並べます。上下左右の配置と自動非表示を設定でき、ポインター・タッチ・キーボードで再表示できます。設定パネルを操作している間は隠れません。自動リロードの設定文言を日本語に揃え、未選択・監視中の区別と用途説明を追加しました。

自動リロードは、制作中に選択した台本ファイルの保存を検知してプレビューへ反映するための機能です。監視するファイルを選ぶまで監視は始まりません。配布先で台本を編集しない場合は利用する必要はありません。

## 依存と公開経路

app-shell 0.3.0、Camera Source 0.19.0、Async Input 0.7.2、Bubble 0.13.2、Teachable Machine 3.5.3を固定します。共通Dockの上流を含め、直接・間接依存の下流packageを依存順にbumpします。台本のDSL版は4.0のままで、安定版の推奨は3.2.3を維持します。

公開SB3から同じ内容のPackager HTMLを生成し、ダウンロードページに「ブラウザーで開く」を追加します。Editorでは公開GUI側のstageControls/cameraControls APIを利用します。
