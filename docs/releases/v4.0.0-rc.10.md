## 概要

v4.0.0-rc.10は、DSL 4.0 Standard SB3が読み込むTurboWarp TM系のextension ID、artifact、依存packageを
`tm`系へ統一する公開候補です。repository、Pages URL、docs/samples URL、SB3内extension IDは現在名の
`tm-kamishibai`と`kubohiroyatm`に揃え、旧称が表に残らないよう整理しました。

## rc.9からの主な変更

- TurboWarp TMを`@kubohiroya/turbowarp-tm@2.0.0`へ更新
- SB3内のpose recognition extension IDを`kubohiroyatm`へ更新
- DSL 4.0のpose model resource、asset lock、asset vendor、pose archive formatを`tm`表記へ更新
- README、site、release metadata、download catalogのrepository／Pages／docs／samples URLを`tm-kamishibai`系へ更新
- 上流TurboWarp extension dependenciesを最新minorへexact pin
- npm package名`@kubohiroya/tmpose-kamishibai`とCLI executable `tmpose-kamishibai`は、4.0.0-rc.10では互換のため維持

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- npm package名とCLI executableは互換のため維持します。
- SB3内のmanaged extension IDは`kubohiroyatm`です。旧IDを前提にした外部検査や手作業のSB3差分確認は更新が必要です。
- DSL 3.2 converterはpose model URL表記を`TMURL`として扱います。
- 安定版の推奨は引き続き3.2.3です。4.0.0-rc.10は正式版前の検証用公開候補です。
