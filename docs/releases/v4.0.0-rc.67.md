# 4.0.0-rc.67 — 定義監査・宣言省略・簡易say/think

- asset・actor・control・cover・recognition・textStyle・variable・loading・navigationの定義と参照を監査するCLIを追加します。未使用と確定した定義だけを明示オプションで別出力へ除去し、元の作品と素材を保持します。
- ツールチェインとランタイムの双方で、SB3内の背景・音・衣装をasset宣言なしで参照できます。未宣言actorは同名spriteの最初の衣装、未指定coverはStageの最初の背景・音、variables.startSceneIndexは1を使います。明示値を優先します。
- JSON不要のactor say/thinkのtext・secondsブロックを追加します。対応能力を示さない旧runtime向けには既存SPEC版を生成し、高度なspeech指定はSPEC版を保持します。
- 不正なassets／actors宣言の検出、旧compiled作品の検証後の既定値補完、明示actorのactorName優先を維持する互換性修正を含みます。
- 凍結済みrc.66のメタデータと成果物は保持します。宣言省略により従来coverなしの作品の表示・音が変わる場合があります。startSceneIndexは変数初期値で、開始sceneを選ぶ指定とは別です。

## 検証

既存のrelease cut手順で新しいスナップショットを作成・凍結し、source identityとSB3のハッシュを再ビルドで照合します。対象検証・CIの結果と依存するDocs／Samples PRはIssue #1083・#1084およびApp PR #1086に記録します。物理カメラ・実音声の通し確認は含みません。
