## 概要

v4.0.0-rc.11は、repository、npm package、CLI、Pages、DSL 4.0 Standard SB3の識別子を
`tm-kamishibai`／`kubohiroyatm`系へ揃えた公開候補です。rc.10でTurboWarp TM packageと
embedded extension IDを先行移行し、rc.11でこのrepositoryの公開package名とCLI executableも現在名へ
切り替えました。

## 名前と識別子の決定表

| 種類 | v4.0.0-rc.9以前 | v4.0.0-rc.10 | v4.0.0-rc.11以降 |
| --- | --- | --- | --- |
| product name | `TMPose Kamishibai` | `TM Kamishibai` | `TM Kamishibai` |
| 日本語名 | `TM紙芝居` | `TM紙芝居` | `TM紙芝居` |
| repository | `kubohiroya/tmpose-kamishibai`系URLが一部残存 | `kubohiroya/tm-kamishibai` | `kubohiroya/tm-kamishibai` |
| npm package | `@kubohiroya/tmpose-kamishibai` | 互換のため維持 | `@kubohiroya/tm-kamishibai` |
| CLI executable | `tmpose-kamishibai` | 互換のため維持 | `tm-kamishibai` |
| TurboWarp TM package | `@kubohiroya/turbowarp-tm@1.x` | `@kubohiroya/turbowarp-tm@2.0.0` | `@kubohiroya/turbowarp-tm@2.0.0` |
| TM Extension ID | `tmpose` | `kubohiroyatm` | `kubohiroyatm` |
| Pages URL | `https://kubohiroya.github.io/tmpose-kamishibai/`系 | `https://kubohiroya.github.io/tm-kamishibai/` | `https://kubohiroya.github.io/tm-kamishibai/` |

旧package名、旧CLI名、旧Pages URL、旧release URLは公開済みartifactを再現するためのlegacy識別子です。
現行README、package metadata、download catalog、release metadata、Standard SB3 generatorでは新しい
repository／package／CLI／Pages URLを正本として使います。

## rc.10からの主な変更

- npm package名を`@kubohiroya/tm-kamishibai`へ更新
- CLI executableを`tm-kamishibai`へ更新
- READMEの日英本文、install例、API import例、repository構成説明を現在名へ更新
- DSL 4.0 release metadata、release pins、artifact fingerprintをv4.0.0-rc.11へ更新
- Standard SB3、Web、Packager、CLI buildのruntime quiesceとrecognition lifecycleを分割・検証
- release source／base SB3／generated SB3が`kubohiroyatm`を使う状態を維持

## version matrix

| 系列 | 推奨用途 | package／CLI | TM Extension ID | migration policy |
| --- | --- | --- | --- | --- |
| 3.1／3.2.3 | 安定運用、既存作品、体験会 | 公開済みartifactを維持 | `tmpose` | 既存SB3は差し替えず、そのまま利用する |
| 4.0.0-rc.9以前 | 旧candidateの再現 | `@kubohiroya/tmpose-kamishibai`／`tmpose-kamishibai` | `tmpose` | 同一versionの再公開は行わず、必要なら新candidateへ移行する |
| 4.0.0-rc.10 | TM ID移行の中間candidate | 旧package／旧CLIを互換維持 | `kubohiroyatm` | package／CLI rename前の検証点として保持する |
| 4.0.0-rc.11以降 | 4.0正式版前の現在candidate | `@kubohiroya/tm-kamishibai`／`tm-kamishibai` | `kubohiroyatm` | 新package、CLI、Pages URLを正本として使う |

3.2 artifactのmaintenance lineは、公開済み3.2.3を安定版として維持します。3.2 artifactを同一versionで
new extension IDへ差し替えることはしません。既存の3.1／3.2台本を4.0へ移す場合は
`tm-kamishibai convert-dsl4`を使ってDSL 4.0 YAMLへ変換し、warningを確認したうえで別名の4.0成果物を
buildします。SB3内部のextension IDやopcodeを直接一括置換しません。

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- 4.0.0-rc.11のStandard SB3内のmanaged TM extension IDは`kubohiroyatm`です。
- TM 2.0.0の公開TurboWarp opcodeは`startRecognition`、`stopRecognition`、`isRecognizing`、
  `firstRecognitionMsReporter`です。旧`*Predict*` opcode aliasは追加しません。
- 3.1／3.2作品は推奨安定版3.2.3で継続利用できます。4.0 runtimeへlegacy parserは追加しません。
- 旧release metadataに残る`tmpose-kamishibai`系URLは歴史的な公開先の記録であり、削除・上書きしません。

## 検証

```sh
pnpm verify:full
pnpm pack:smoke
pnpm release:check
```

`pnpm verify:full`はrelease source identity、SB3決定性、extension list、opcode、embedded mapping、
manifest、integrity、Editor／Player／Web／Packager／CLI buildの主要経路、site build、npm package smokeを
検証します。`pnpm release:check`はnpm publish dry-runであり、実際の公開は行いません。

## ロールバック

rc.11を同じversionで差し替えません。問題時は公開済みrc.10または安定版3.2.3を利用し、修正は次の
candidateとして公開します。npm dist-tag、download catalog、Pagesの推奨表示だけを直前の検証済み組へ戻し、
公開済みSB3、release metadata、旧URL、旧packageの履歴は削除しません。
