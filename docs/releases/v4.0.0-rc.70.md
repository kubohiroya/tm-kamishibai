# 4.0.0-rc.70 — remote認識モデルの重みパス読込を修正

公開済みrc.69へ重みパス修正を加えた候補です。rc.69の台本アイコンと最新mainのサイトヘッダ修正を含みます。関連: [Issue #1090](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1090)・[PR #1091](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/1091)。DSLの版は4.0のままです。

## 修正内容

Teachable Machineの公開モデルが`model.json`の`weightsManifest.paths`に`./model.weights.bin`を指定すると、正しい`delivery: remote`・`source.url`設定でも読込を拒否していました。先頭の`./`を一つだけ正規化し、runtime・素材候補検証・local/rsync変換で同じroot filenameとして扱います。

親・子ディレクトリ、絶対パス・URL、二重の`./`、複数重み、不一致ファイルは引き続き拒否します。新しい有効化フラグやDSL版は追加しません。既存SB3の埋込ランタイムは自動更新されないため、修正の利用にはこの版のCLI・ランタイムを揃えた再生成が必要です。

## 検証

- 修正前にruntime・素材候補・変換の3回帰で失敗を再現し、修正後は対象42テストと生成runtime整合性1テストが成功。
- 指定URLの実モデル3ファイルを読込・素材検証・adapterへ渡し、クラス名`pose1`・`pose2`とroot filenameを確認。compositionは模擬で、実TFJSによるclassifierのロードも確認済み。カメラを使った実認識は未検証。
- 旧候補では通常CIの219ファイル2,129テスト、凍結照合・lint・format・型検査が成功。最新mainを統合したrc.70の検証結果はIssue #1090へ記録します。
