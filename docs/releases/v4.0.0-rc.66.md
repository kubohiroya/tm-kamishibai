# 4.0.0-rc.66 — バンドル表示メタデータの修正

- バンドル自身の名称・版数・npm package・GitHub・Pages・日英説明を機能拡張セキュリティへ渡します。
- 製作者名とURLはpackage.json.author.name/urlを使用し、プレビューとブロックのアイコンを共通化します。
- sb3-toolchainの任意metadataに対応する0.19.1を使用し、現行の3ランタイムを再生成します。
- 内包メンバーのnoticeとサンドボックス要件を維持し、凍結済み4.0.0-rc.65のmetadata・成果物を保持します。

## 検証

既存のpnpm verify:releaseで型・unit/integration・対応ブラウザ・サイト・配布パッケージを検証します。結果は公開運用記録へ記録し、このノートだけを完了根拠にはしません。

## 公開

版付きSB3とnpmは、リリースジョブが凍結成果物を照合して公開した後に利用できます。

## ロールバック

既存の公開済み版へ戻します。既公開artifact/tag/npmを上書きせず、公開後の修正は新しい版で行います。
