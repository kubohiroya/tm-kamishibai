# v4.0.0-rc.47 — 原本解放の失敗・再入と停止後exportの修正

## 変更内容

- PR #996の原本bundle解放修正を含むDSL 4.0プレリリースです。cleanupに失敗したownerを保持し、明示releaseで未完了分だけを再試行します。同期callbackやabort通知からの再入も同じ処理へ合流します。
- dispose後は遅れて完了したread/exportも拒否し、呼出側へ渡したコピーの独立所有を維持します。呼出側の取消しだけで共有KVS sessionを致命障害にしません。
- DSL 4.0のStandard物語制御と既存台本の互換性を維持します。進行中の上位session cleanup/KVS内部の未公開修正は含めません。
