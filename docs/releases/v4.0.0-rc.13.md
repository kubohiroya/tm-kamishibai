## 概要

v4.0.0-rc.13は、`TurboWarp-Kamishibai`への改名後の最初の公開候補です。Standard SB3に埋め込む
TurboWarp TM拡張を`@kubohiroya/turbowarp-tm@3.2.0`へ上げ、rc.12の公開後に入ったDSL 4.0の追加、
共有packageへの移行、名称移行をまとめます。rc.12は公開済みのため同じversionでは差し替えず、
新しいcandidateとして切ります。

## rc.12からの主な変更

- 埋め込みTurboWarp TMを`2.0.0`から`3.2.0`へ更新（#800）
- Async Input `0.6.0`→`0.7.0`、SVG Text `0.9.0`→`0.10.0`、Runtime Expression `0.5.0`→`0.6.0`（#827）
- npm packageを`@kubohiroya/turbowarp-kamishibai-app`へ、repositoryを`turbowarp-kamishibai-app`へ、
  product表記を`TurboWarp-Kamishibai`へ移行（#814、#823）
- CLI実行ファイル名を`turbowarp-kamishibai`へ変更し、`tm-kamishibai`を非推奨の互換aliasとして維持（#824）
- site表記とnavigationを`@kubohiroya/turbowarp-kamishibai-site-navigation@0.2.0`へ追随（#806、#825）
- **破壊的変更**: Standard profileで暗転していた8個のfeature flagを既定ONへ変更（#796）
- **破壊的変更**: 変数更新のcore actionを追加し、write blockを畳む（#797）
- BGMの停止・fade-out・音量を標準DSLへ追加（#798）
- `Actor.setText`にcontent run（ruby含む）とplain text射影を追加（#799）
- asset永続化をAsset CacheとKVSへ移行（#816）、runtime adapterとlive reload controllerを共有packageへ分離（#809、#812）

## TurboWarp TM 3.2.0について

TurboWarp TMの「Upgrading from 2.x」のとおり、block surface、composition API、offline PoseNet
bundle APIは変わっていません。composition APIの差分は追加だけ（`selectComputeBackend()`、
`getComputeBackend()`、任意の`compute`／`computeMode`）で、PoseNetの重みシャードはバイト一致です。
SB3に埋め込む`dist/tm.js`は64 KBから73 KBになりました。

TurboWarp-KamishibaiはTensorFlow.js 1.3.1とTeachable Machine Pose 0.8.6のbrowser runtimeを自前で
供給し、TurboWarp TMの`dist/runtime.js`（TensorFlow.js 4.22.0同梱）は使いません。そのため3.xの
compute backend negotiationはこの経路では働かず、TensorFlow.jsが選んだbackendをそのまま使います。

## そのほかの埋め込み拡張について

SVG Text 0.10.0とRuntime Expression 0.6.0は、changelog上、repository scriptのTypeScript移行と
Vite 8でのbundle再生成だけで、runtime API、Extension ID、opcodeは変わりません。Async Input 0.7.0は
changelogに記載がなく、配布物の差分は`dist/async-input.js`と`dist/composition.js`の再生成です。

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- 4.0.0-rc.13のStandard SB3内のmanaged TM extension IDは`kubohiroyatm`です。
- CLI実行ファイル名は`turbowarp-kamishibai`です。`tm-kamishibai`は非推奨aliasとして残りますが、
  `bin/`内のファイル名は`turbowarp-kamishibai.mjs`だけです。固定pathでCLIを呼ぶ下流は追随が必要です。
- #796と#797はStandard profileの既定値とwrite blockを変えるため、rc.12向けに書いた台本の挙動が
  変わる場合があります。
- rc.12以降、say／thinkはTurboWarp BubbleのSVG overlayに描画され、`Scratch.looks`には書き込みません。
  台詞を`Scratch.looks`から読む外部の検証はoverlayから読むよう変更が必要です。
- 3.1／3.2作品は推奨安定版3.2.3で継続利用できます。
