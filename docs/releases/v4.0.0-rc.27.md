## 対象と変更

`kamishibaiConfig [LABEL]`ハットを追加しました（[#919](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/919)）。CLIの`author-block-dsl`でYAMLからブロック台本へ変換すると、`control`・`asset`・`cover`・`textStyle`・`variable`・`loading`・`recognition`の定義をこのハットへ接続します。actorとsceneは従来の`kamishibai`ハットへ接続します。

Stageの名前なし`kamishibai`は、全ターゲットの設定ハットを暗黙に読み込みます。空名称の設定を最初に読み込み、以降は名前順に読み込みます。同名の設定ハットが複数存在する場合は、空名称も含めて実行時エラーになります。既存の`kamishibai`へ直接接続した設定定義も引き続き読み込めます。

## 互換性

- DSL document versionは文字列`kamishibai: "4.0"`を維持します。
- CLI・開発環境はNode.js 24.0.0以上です。
- 既存の機能フラグは既定OFFを維持します。
- 既存SB3の埋込runtimeは自動更新されません。設定ハットを利用するSB3は本版のCLI・runtimeで再生成してください。
- npmは`next`で配布し、Pagesの推奨安定版は`3.2.3`を維持します。

## 検証・公開固定値

収録する5件のマージ後にruntimeとSB3を生成・凍結し、`pnpm verify:full`とnpmの新規導入検証の結果を記録します。

## ロールバック

問題時はnpmの`next`を公開済みrc.26へ戻し、利用側もversion・依存lock・base artifactのpinをrc.26へ戻します。`latest`を更新した場合は同じくrc.26へ戻します。版番号・凍結情報・READMEの変更は本版のcut commitをrevertします。公開済みversionの成果物は差し替えず、修正は次RCで公開します。
