## 対象と変更

ローカルrc.31候補のCamera Source更新を、公開済みrc.32を含むmainへ移します。Camera Sourceを0.15.0から0.17.1へ更新し、依存・lockfile・同梱定義・release pin・ライセンス・生成runtimeを同期します。rc.32の通常bundle／sandbox案内のカテゴリ色修正を維持します。

カメラ許可ボタンの3ブロック（startSharedCameraFromCameraButton、hideCameraButton、cameraButtonAvailable）を同梱します。host取得済みのpose streamへ参加し、二重取得やhost trackの停止を行わない共有経路を維持します。

元の作業branchにある編集プレビュー・共通フォーム配布作業は含めません。旧rc.31候補と公開済みrc.32の成果物を差し替えず、rc.33を新規凍結します。

## 互換性

- DSL document versionは4.0、既存feature flagの既定値と推奨安定版3.2.3を維持します。
- Camera Sourceの旧mirrored/MIRROREDを直接使う作品はpreviewFlip/PREVIEW_FLIPへ移行してください。appのhost取得・共有経路は旧引数を使用しません。
- カメラの実機許可UIと、代替DOM／streamによる回帰検証は区別します。
- Node.js 24以上。既存SB3のruntimeを更新するには再生成が必要です。
