## 変更

Camera Sourceを公開npm0.18.0へ更新し、本体から編集用Ajv・汎用YAML・React/RJSFを除いた軽量runtimeを同梱します。GUIは公開共通フォーム0.3.0を共有し、タブ・グループ・グリッドと固定Schema向け入力を提供します。専用camera editor repositoryは新設しません。

公開済みrc.32と、マージ済みrc.33候補のmetadataは保持し、本版を新規凍結します。DSL version4.0と推奨安定版3.2.3は維持します。

## 公開と操作確認

公開Editorのフォーム用リンクは`blockEditorDialogs=1&blockEditorSourceForms=1&blockEditorCommonLayout=1`を起動URLへ指定します。各フラグは起動時固定・既定OFFです。公開GUI/coreのsource pinとCI/E2Eを照合して配信します。

GitHub ReleaseとPagesのSB3を公開し、npm CLIは既存公開版rc.27を維持します。今回のnpm公開対象は共通フォーム0.3.0・Camera Source0.18.0・sb3-toolchain0.16.0です。公開済みSB3を使う実フォームの編集・不正値・保存・Cancel・再表示・保存SB3の確認結果は[Issue #941](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/941)へ記録します。カメラ実機の検証を行ったとは扱いません。
