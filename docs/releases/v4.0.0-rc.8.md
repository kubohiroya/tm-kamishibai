## 概要

v4.0.0-rc.8は、DSL 4に名前付き`bubbleClosePolicies` registryとsay／think actionの
`closePolicy`参照を追加し、`@kubohiroya/turbowarp-bubble@0.10.0`をexact pinする公開候補です。
Bubble 0.10.0のnpm package、GitHub Release、Pages、CDNを確認してから、この下流成果物を再生成します。

## rc.7からの主な変更

- top-level `bubbleClosePolicies` registryを追加
- say／think actionに`closePolicy`を追加
- policy triggerとして`condition`、`timeout`、`condition-or-timeout`を提供
- compile時に名前付きpolicyを既存runtime入力の`seconds`／`waitFor`へ正規化
- policy参照と従来の`seconds`／`waitFor`の競合をschemaとfrontendで拒否
- 未定義policy、空condition、0以下のtimeoutを決定的な診断として拒否
- Bubbleを0.9.0から0.10.0へexact pinし、Standard bundleとprovenanceを更新

## 互換性

- DSL document versionは引き続き文字列`kamishibai: "4.0"`です。
- `bubbleClosePolicies`と`closePolicy`を使わないrc.7以前のDSL 4台本は変更不要です。
- 従来の`seconds`と`waitFor: advance`は引き続き利用できます。
- 同じsay／think actionで`closePolicy`と`seconds`または`waitFor`を併用することはできません。
- Standard Runtimeは名前付きpolicyをcompile時にsnapshotし、既存のspeech lifecycleへ渡します。
