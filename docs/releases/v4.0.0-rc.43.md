# v4.0.0-rc.43 — Player開始待ちとタイトル操作部の重なりを修正

Player開始前にOfficial Websiteボタンと閉じるボタンが緑旗オーバーレイより前面へ出る問題を修正します。タイトル操作部をcanvasの上・開始オーバーレイの下へ配置し、開始後のタイトル操作と空白部のcanvas入力を維持します。再生用runtimeにも同じ変更を反映しています（PR #973、Issue #780）。

DSLは4.0のままで、既存台本との互換性と動画の標準ONを維持します。Safariは今回の検証対象外です。
